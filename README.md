One original fortune for a houseplant (114 characters):

> You will outgrow this pot by spring, and your keeper will buy you a bigger one, pretending it was always the plan.

The setup is a prediction for the plant itself — it will outgrow its pot. The punch turns on the keeper, who will buy the bigger pot while pretending that was always the plan. Kind, warm, and written for this plant in this pot on this windowsill, not for any plant anywhere.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
